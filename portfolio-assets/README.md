# Portfolio Assets

A dedicated home for assets and interactive experiences used by my Framer portfolio.

## Folder structure

- `assets/` — images, icons, SVGs, and other static assets
- `interactive/` — standalone HTML, CSS, and JavaScript experiences to embed in Framer
- `data/` — JSON files and datasets for interactive visualisations

## Usage notes

- Use GitHub raw file URLs for public static files when appropriate.
- Use GitHub Pages or another static host for standalone interactive pages that need their own public URL.
- Keep filenames descriptive and use lowercase kebab-case.
